<Info>
**Handy Tips**
</Info>

If you are a Current Account user having a RazorpayX/RBL Bank account ledger in TallyPrime, [create a new ledger](#create-a-ledger) for RazorpayX Bank. 

All existing unpaid bills that you wish to pay through RazorpayX using this integration will be credited to the new RazorpayX ledger account.

## Create a Ledger

To create a ledger:
<Steps>
<Step title="Open TallyPrime and navigate to the **Gateway of Tally**.">
Open TallyPrime and navigate to the **Gateway of Tally**.
</Step>
<Step title="Go to **Create**, as shown.">
Go to **Create**, as shown.

</Step>
<Step title="Select **Ledgers** and enter a name for the ledger.">
Select **Ledgers** and enter a name for the ledger.
</Step>
<Step title="In the **Bank Accounts Details** section, type RAZ in the **Bank Na...">
In the **Bank Accounts Details** section, type RAZ in the **Bank Name** field. A **List of Banks** pop-up page is displayed.

</Step>
<Step title="Select **RazorpayX (India)**.">
Select **RazorpayX (India)**.
</Step>
<Step title="Set the fields under **Bank Configuration** to **Yes** or **No** as...">
Set the fields under **Bank Configuration** to **Yes** or **No** as required.

- Set **Enable e-Payments** under **Bank Configuration** to **Yes**. This is mandatory.
- Under Enable e-Payments, select **Set/alter e-Payments configuration**. Select the requisite parameters for e-Payment.
</Step>
<Step title="Click **Yes** in the Accept window to save your selection.">
Click **Yes** in the Accept window to save your selection.
</Step>
<Step title="Click **Yes** in the **Confirm RazorpayX ledger creation** window.">
Click **Yes** in the **Confirm RazorpayX ledger creation** window.
</Step>
</Steps>

You have successfully created a ledger for RazorpayX. There are other ledger features available in Tally, which you can use to [map the expenses and taxes to the ledgers](/x/vendor-payments/tally/bring-bills#ledger-and-mapping) as per the transactions made.

## List of APIs

The table below lists the various endpoints and gives a brief description of each:

API Endpoint | Description
---
[Normal Payout API](/api/x/payout-wallet/create/contact) Includes: - [Create a Contact API](/api/x/payout-wallet/create/contact)
- [Create a Fund Account of type `wallet` API](/api/x/payout-wallet/create/fund-account)
-  [Create a Payout API](/api/x/payout-wallet/create/payout)
 | Creates a normal payout to your Contact's Amazon Pay Gift Card. 
---
[Composite Payout API](/api/x/payout-wallet/create/payout-composite) | Create a Contact, Fund Account and make the payout to your Contact's Amazon Pay Gift Card at once using [Composite API](/api/x/payout-composite).

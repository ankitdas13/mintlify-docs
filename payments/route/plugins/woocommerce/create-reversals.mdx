## Create Reversals From WordPress Admin Dashboard

To create a reversal:

<Steps>
<Step title="Step 1">
Log in to the **WordPress Admin Dashboard** and navigate to **Razorpay Route woocommerce** → **Transfers**.
</Step>
<Step title="Step 2">
Click the required **Transfer Id** to create a reversal.
</Step>
<Step title="Step 3">
Click **Create Reversal**.

</Step>
<Step title="Step 4">
Enter the **Reversal Amount** and click **Create Reversal**.

</Step>
</Steps>

The amount is reversed. You can see the details in the **Reversals** tab.

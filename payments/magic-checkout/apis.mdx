---
title: "Magic Checkout APIs"
description: "You can use the following APIs related to Magic Checkout:"
---

- **Coupon Code**: Use the [Coupon Code APIs](/payments/magic-checkout/apis/coupon-code) to send coupon details to Razorpay. Razorpay will create the coupon codes, which you can then apply to transactions.
- **Customer Address**: Use the [Customer Address APIs](/payments/magic-checkout/apis/customer-address) to upload customers' billing and shipping addresses in bulk. 
- **Shipping Information**: Use the [Shipping Information APIs](/payments/magic-checkout/apis/shipping-info) to send the customer's shipping information to Razorpay.

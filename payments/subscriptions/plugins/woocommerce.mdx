## Advantages

- Razorpay Subscriptions plugin provides a quick and customer-friendly integration.
- No need to create Plans or Subscriptions using the Razorpay Dashboard or Razorpay APIs. All this can be done easily from your WooCommerce Dashboard.
- Customers can make payments on your website without any redirections.
- You can accept recurring payments using Razorpay Subscriptions plugin on your WooCommerce website via Credit Card, Debit Card, Netbanking and UPI payment methods.

## Plugin Dependencies

You must have the following installed for the plugin to work:

Platform/Plugin/Language | Version
---
WordPress | 3.9.2 or higher
---
[WooCommerce Plugin for WordPress](https://wordpress.org/plugins/woocommerce/) | 2.4 or higher
---
[WooCommerce Subscriptions Plugin](https://woocommerce.com/products/woocommerce-subscriptions/) | 2.2 and above
---
[Razorpay WooCommerce Plugin](https://wordpress.org/plugins/woo-razorpay/) | 2.0.0 and above
---
PHP | 5.6.0 or higher
---
PHP-cURL | N/A

<Warning>

**Watch Out!**

Subscriptions plugin v2.3.6 for WooCommerce relies on [Razorpay WooCommerce Plugin](/payments/payment-gateway/ecommerce-plugins/woocommerce) v4.5.4.

</Warning>
## Prerequisites

- Create a [Razorpay account](https://dashboard.razorpay.com/signup)
- Understand the [payment flow](/payments/payment-gateway/how-it-works) process.
- Generate the API keys from the Dashboard. You can use the [Test mode keys](/payments/dashboard/account-settings/api-keys#test-mode-api-keys) for testing and later switch to [Live mode keys](/payments/dashboard/account-settings/api-keys#live-mode-api-keys) when going live with the integration.

## List of Disputes APIs

The table below lists the various Disputes APIs and gives a brief description of each API:

API | Description
---
[View all disputes](/api/disputes/fetch-all) | API to fetch all disputes.
---
[View a dispute by dispute id](/api/disputes/fetch) | API to view dispute details by providing the dispute id.
---
[Accept a dispute](/api/disputes/accept) | API to accept a dispute.
---
[Contest a dispute](/api/disputes/contest) | API to contest a dispute.

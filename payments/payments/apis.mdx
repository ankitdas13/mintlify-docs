## List of Payments APIs

The table below lists the various Payments APIs and gives a brief description of each API:

 API | Description
 ---
 [Capture a payment](/api/payments/capture) | API to capture a payment
 ---
 [Fetch a payment](/api/payments/fetch-with-id) | API to view details of a payment
 ---
 [Fetch multiple payments](/api/payments/fetch-all-payments) | API to get details of all payments
 ---
 [Fetch payments based on orders](/api/payments/fetch-payments-orders)|  API to get payments based on orders
 ---
 [Fetch card details for a payment](/api/payments/fetch-card-details-payment)| API to get the card details for a payment
 ---
 [Update a payment](/api/payments/update) | API to update notes of a payment
 ---
 [Payment Downtime API](/api/payments/downtime) | API for payment downtime and webhooks

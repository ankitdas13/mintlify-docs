You can assign predefined roles to your team members and limit their access to the Dashboard. The below table explains each role and the Optimizer routes permissions associated with it. Know more about [Dashboard Roles](/payments/dashboard/account-settings/manage-team).

Role | Permissions
---
Owner |- Add Optimizer Provider.
-  Update Optimizer Provider.
-  Fetch Optimizer Gateways.
-  Fetch Merchant Optimizer Provider.
-  Fetch Optimizer Merchant Methods.
-  Create Optimizer Rules.
-  Update Optimizer Rules.
-  Read Optimizer Rules.

---
Admin | - Add Optimizer Provider.
-  Update Optimizer Provider.
-  Fetch Optimizer Gateways.
-  Fetch Merchant Optimizer Provider.
-  Fetch Optimizer Merchant Methods.
- Create Optimizer Rules.
-  Update Optimizer Rules.
- Read Optimizer Rules.

---
Manager | -  Fetch Optimizer Gateways.
-  Fetch Merchant Optimizer Provider.
- Fetch Optimizer Merchant Methods.
- Read Optimizer Rules.

---
Operations | - Fetch Optimizer Gateways.
-  Fetch Merchant Optimizer Provider.
- Fetch Optimizer Merchant Methods.
-  Read Optimizer Rules.

---
Finance | -  Fetch Optimizer Gateways.
- Fetch Merchant Optimizer Provider.
-  Fetch Optimizer Merchant Methods.
-  Read Optimizer Rules.

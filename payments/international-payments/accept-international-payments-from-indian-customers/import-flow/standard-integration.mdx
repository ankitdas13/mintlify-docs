Your Indian customers can make payments using local payment methods such as credit cards, debit cards, UPI and netbanking. The funds are settled in your overseas bank account. Know more about [Import Flow](/payments/international-payments/accept-international-payments-from-indian-customers).

## Prerequisites

- Create a [Razorpay account](https://dashboard.razorpay.com/signup).
- Understand the [payment flow](/payments/payment-gateway/how-it-works) process.
- Generate the [API Keys](/api/authentication#generate-api-keys) from the Dashboard. To go live with the integration and start accepting real payments, generate Live Mode API Keys and replace them in the integration.

You can use the Terms and Conditions APIs to fetch terms and conditions for a sub-merchant. Check the [workflow to fetch and accept terms and conditions](/partners/aggregators/onboarding-api#terms-and-conditions-workflow) for a sub-merchant.

Fork the Razorpay Postman Public Workspace and try the Terms and Conditions APIs using your [Test API Keys](/partners/aggregators/onboarding-api#api-authentication/).

### Endpoints

  - **get** `/v2/products/:product_name/tnc` - Fetch Terms and Conditions: 
    Retrieves terms and conditions for a sub-merchant.
  

  - **post** `/v2/accounts/:account_id/products` - Accept Terms and Conditions: 
    Use the Product Configuration API to accept terms and conditions for a sub-merchant.

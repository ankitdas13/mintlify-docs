---
title: "Media Bank"
description: "The **Media Bank** lets you upload, store and manage images, banners, videos and logos in one central place. These media files can be used across **Billme Dashboard** for creating or designing user journeys, surveys, digital bills, campaigns and so on."
---

## Key Features

- Upload and tag creative assets for easy reuse
- Use media across campaigns, banners and popups
- Preview formats and sizes before inserting
- Share media access with specific roles or teams

## Upload and Manage New Media

To upload a new media file:

<Steps>
<Step title="Under **Manage** section, click **Media Bank**. The **Media Bank**...">
Under **Manage** section, click **Media Bank**. The **Media Bank** page appears.

</Step>
<Step title="Click **+ Upload Media**. The **Upload New Data** page appears.">
Click **+ Upload Media**. The **Upload New Data** page appears.
</Step>
<Step title="Upload your file and enter a file name and description.">
Upload your file and enter a file name and description.
</Step>
<Step title="Click **Import Data**. The new media file is uploaded and stored in...">
Click **Import Data**. The new media file is uploaded and stored in the **Media Bank**.
</Step>
<Step title="Hover over to **Actions** against the file you want to manage.">
Hover over to **Actions** against the file you want to manage.
- You can view and download the files.
- You can delete the files.
</Step>
</Steps>
